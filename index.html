Console type

The console type decides which kstuff build the payload menu offers — kstuff.elf for retail, kstuff-devkit-only.elf for devkit. It is stored in this browser rather than passed in the address bar, because the exploit pages bake their run parameters in and refuse a non-canonical query.

It is stored per origin, so choosing here covers the three soniciso1.github.io builds. A console loading the site through a local DNS host is a different origin and keeps its own choice — pick it again there.
